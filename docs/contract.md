# PaperBridge implementation contract

React SPA + Firebase Authentication, Firestore, Storage, callable Cloud Function `api` (us-central1). All writes through api except Storage uploads to papers/{uid}/{paperId}/{filename}. All dates numeric milliseconds. All records return id.
Callable payload {action, ...fields}. Read calls via api for simplicity; return {data: value}. Client function call(action,payload) unwraps .data.data.
Profiles: id,name,role(researcher|endorser),headline,institution,bio,categories:string[],acceptingRequests:boolean,weeklyCapacity:number,arxivUrl,orcid,publicProfile:boolean. email only private users doc. Public profiles in profiles.
Papers: id,ownerId,title,abstract,category,authors,storagePath,fileName,text,visibility(private|public),createdAt,updatedAt. Manuscripts private by default; paper list owner only. API paper.get checks owner or participating reviewer.
Requests: id,paperId,title,category,requesterId,reviewerId,requesterName,reviewerName,message,endorsementUrl,status(pending|reviewing|changes_requested|accepted|declined|withdrawn|endorsed),createdAt,updatedAt. accepted means willing, endorsed is manually confirmed external completion. No automatic official verification.
Actions: profile.save{profile}, profile.get{id?}, directory.list{category?,search?}, paper.save{paper},paper.list{},paper.get{id},paper.delete{id}, request.create{paperId,reviewerId,message,endorsementUrl},request.list{},request.get{id},request.status{id,status,note?},request.messages{id},request.comment{id,body}, annotation.list{paperId},annotation.save{paperId,page,quote,body,color,visibility(private|shared),rects?},annotation.delete{id},feed.list{},feed.post{body,paperId?,arxivUrl?},feed.like{id},feed.comments{id},feed.comment{id,body},feed.delete{id},follow.toggle{id},follow.list{},chat.list{},chat.open{userId},chat.messages{id},chat.send{id,body},notifications.list{},notifications.read{},leaderboard.list{period:week|all},account.export{},account.delete{},report.create{targetId,reason},block.toggle{userId}.
AI: separate agent implementing functions/src/ai.ts; functions api delegates ai.* actions to exported handler. AI key settings returned metadata only; encrypted at rest with secret. AI consent per job. Return model catalogs dynamically; 3 tasks evidence,originality,reviewer with per-task model/provider. AI security failures explicit.
No fake members on production. The interactive fixture is development-only, with a clear demo banner and in-memory records; production builds ignore demo query parameters. Production empty states invite genuine participants.

Revision extension: Papers return version (legacy default1) and versions (latest20 metadata entries including current). paper.save accepts expectedVersion to reject stale writes; storagePath/text changes increment revision, metadata-only changes do not. Active requests lock category. paper.version.get{id,version} returns selected PDF metadata/downloadUrl plus currentVersion; owner/active reviewer only, even for public papers. Notes include paperVersion (legacy1); annotation.save accepts expected paperVersion and rejects stale revision, archived notes are read-only except deletion. Active request updates expose paperVersion,currentPaperTitle,paperUpdatedAt,revisionAvailable while preserving initial title and status.

List DTOs: paper.list omits text and versions; supplies textCharacterCount (legacy-compatible) and version. paper.get retains full owner/authorized manuscript data. ai.jobs returns only id,ownerId,paperId,title,status,createdAt,updatedAt; ai.job.get retains the full private audit report.
