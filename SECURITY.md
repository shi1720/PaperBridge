# Security

PaperBridge handles private manuscripts and research discussions. Please report suspected vulnerabilities privately to **shivam1720406@gmail.com**, with “PaperBridge security” in the subject.

Include the affected workflow, steps to reproduce, expected behavior and the potential impact. Use accounts and files you control. Do not access another person's manuscripts, post credentials, or include private research in a public issue.

Do not commit provider keys, SMTP credentials, Firebase service-account keys or real user exports. Local environment files and emulator secrets are ignored by Git. The example key in the integration test is synthetic and cannot authenticate to a provider.

Security improvements are maintained on the main branch. No response-time or bounty commitment is implied.
